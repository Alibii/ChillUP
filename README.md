# ChillUP

Единая подписка на компьютерные клубы, антикафе, боулинг, настольный теннис
и VR-арены в Казахстане и России — "один пасс, безлимитные посещения".

🔗 **Демо фронтенда:** https://chillup-kz.vercel.app
🔗 **Репозиторий:** https://github.com/Alibii/ChillUP

## Структура репозитория

- **`project/`** — фронтенд (дизайн-прототип на React/Babel, статические HTML/CSS/JS). Страницы: Главная, Тарифы, Партнёры, FAQ, Вход, Регистрация, Личный кабинет. Локализация RU/ҚАЗ (`project/i18n.js`) и настоящая генерация QR-кода в личном кабинете (`qrcode-generator`). Задеплоено на Vercel как статика.
- **`backend/`** — бэкенд на Django + Django REST Framework, PostgreSQL. Полная документация по установке и API — в [`backend/README.md`](backend/README.md).

### Деплой фронтенда на Vercel

Git-автодеплой отключён (создавал дублирующиеся проекты в этом аккаунте) —
обновление продакшена делается вручную:

```powershell
cd project
vercel --yes --prod
vercel alias set <новый-deployment-url> chillup-kz.vercel.app
```

## Быстрый старт

Фронтенд — статические файлы, ничего собирать не нужно, откройте
`project/ChillUP.html` в браузере или разверните `project/` на любом
статическом хостинге.

Бэкенд требует локальный PostgreSQL и Python-окружение — см.
[`backend/README.md`](backend/README.md) для полной инструкции (миграции,
сид-данные, переменные окружения, обзор API).

## Статус

Бэкенд реализован и проверен end-to-end: регистрация/вход, тарифы,
подписки (триал/продление/заморозка/отмена), партнёры с фильтрами,
QR-доступ и чек-ин/чек-аут, дашборд, FAQ. Оплата пока работает через
заглушку (`MockPaymentProvider`) — подключение реального платёжного шлюза
(CloudPayments/Kaspi Pay и т.п.) ещё предстоит.

Фронтенд локализован (RU/ҚАЗ, переключатель в шапке) и в личном кабинете
генерирует настоящий сканируемый QR-код (обновляется раз в 60 секунд).
Фронтенд и бэкенд пока не связаны между собой (фронтенд использует моковые
данные из своих `.jsx` файлов, QR-код на фронтенде кодирует демо-токен, а
не настоящий подписанный токен из `backend/visits/tokens.py`).
